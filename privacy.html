Privacy

Berty's Botz is classroom software for Solvay Middle School Technology Education.

  • No student accounts.
  • No analytics.
  • No names, aliases, roster ids, or class codes in saved files.
  • Save is a local .bertybots.json the student picks (Downloads or a Drive folder they already use).
  • This GitHub repo holds the app source only. Student machines do not get pushed here.

If you would not put it on the projector, do not put it in a Botz file.
